CLAUDE.md — contexte permanent de l'assistant
# Règles de code — projet TLSC

## Contexte
Adaptation au moment du test et sortie anticipée pour ViT en imagerie médicale.
Formalisme de référence : docs/01-cadre-theorique.md. Toute notation en vient.

## Notation (ne jamais renommer)
z : embedding L2-normalisé (B, d)  |  mu : centroïdes (K, d)  |  T : température
H : entropie de Gibbs  |  F : énergie libre = -T·logsumexp(-d²/T)  |  E : énergie moyenne
theta_adapt : LayerNorm du BACKBONE + prompts  |  theta_frozen : tout le reste

## Standards
- Type hints partout, docstrings NumPy, `from __future__ import annotations`.
- Aucune valeur numérique de performance en dur, jamais, même en commentaire.
- Stabilité numérique : `log_softmax` et `logsumexp`, jamais `p.log()`.
- Pas de `.item()` ni de `.cpu()` dans une boucle chaude.
- Tout nouveau module scientifique arrive avec son test dans tests/.

## Pièges connus de ce projet — à ne pas reproduire
1. Les forward hooks NE PEUVENT PAS interrompre le calcul. La sortie anticipée
   exige une boucle explicite sur `model.blocks`.
2. Les têtes de projection contiennent des LayerNorm. Elles NE DOIVENT PAS entrer
   dans theta_adapt : ne parcourir que `model.backbone.modules()`.
3. Mesure de latence : échauffement + `torch.cuda.synchronize()` + `cuda.Event`.
4. Le comptage de FLOPs inclut les passes ARRIÈRE (facteur ~2 par passe avant).
5. theta_adapt est restauré après chaque lot. Une dérive entre patients est un bug.

S3

Le noyau formel — observables de Gibbs

2 h

Le fichier le plus important du dépôt. Recopiez-le intégralement : c'est le seul endroit où une erreur ne provoque aucun plantage mais fausse silencieusement chaque résultat du papier.

tlsc/core/gibbs.py
"""Observables thermodynamiques de l'espace latent.

Convention : embeddings et centroïdes L2-normalisés, donc
E_k(z) = ||z - mu_k||^2 = 2 - 2<z, mu_k> ∈ [0, 4].
Toutes les fonctions sont différentiables et opèrent par lots.
"""
from __future__ import annotations

import torch
from torch import Tensor


def squared_distances(z: Tensor, mu: Tensor, normalized: bool = True) -> Tensor:
    """Distances euclidiennes au carré entre embeddings et centroïdes.

    Parameters
    ----------
    z : Tensor, shape (B, d)
    mu : Tensor, shape (K, d)
    normalized : bool
        Si True, utilise l'identité sphérique — exacte et moins coûteuse.

    Returns
    -------
    Tensor, shape (B, K)
    """
    if normalized:
        return (2.0 - 2.0 * (z @ mu.t())).clamp_min(0.0)
    return torch.cdist(z, mu, p=2).pow(2)


def gibbs(z: Tensor, mu: Tensor, T: float,
          normalized: bool = True) -> tuple[Tensor, Tensor]:
    """Log-postérieur de Gibbs et énergies de configuration."""
    d2 = squared_distances(z, mu, normalized)
    return torch.log_softmax(-d2 / T, dim=-1), d2


def entropy(log_p: Tensor) -> Tensor:
    """Entropie de Gibbs, en nats. Shape (B,)."""
    return -(log_p.exp() * log_p).sum(-1)


def free_energy(d2: Tensor, T: float) -> Tensor:
    """Énergie libre F = -T ln Z. Shape (B,)."""
    return -T * torch.logsumexp(-d2 / T, dim=-1)


def mean_energy(log_p: Tensor, d2: Tensor) -> Tensor:
    """Énergie moyenne <E>. Shape (B,)."""
    return (log_p.exp() * d2).sum(-1)


def observables(z: Tensor, mu: Tensor, T: float,
                normalized: bool = True) -> dict[str, Tensor]:
    """Les trois observables et le postérieur, en une passe."""
    log_p, d2 = gibbs(z, mu, T, normalized)
    return {
        "log_p": log_p,
        "p": log_p.exp(),
        "H": entropy(log_p),
        "F": free_energy(d2, T),
        "E": mean_energy(log_p, d2),
    }
tests/test_gibbs.py
import math
import torch
from tlsc.core.gibbs import entropy, free_energy, observables


def test_uniforme_donne_ln_K():
    """Un point équidistant de tous les centroïdes a l'entropie maximale."""
    K, d = 4, 8
    mu = torch.eye(K, d)
    z = mu.mean(0, keepdim=True)
    z = z / z.norm()
    obs = observables(z, mu, T=1.0)
    assert torch.allclose(obs["H"], torch.tensor([math.log(K)]), atol=1e-5)


def test_degenere_donne_zero():
    """Une température très basse rend l'assignation déterministe."""
    mu = torch.tensor([[1.0, 0.0], [0.0, 1.0]])
    z = torch.tensor([[1.0, 0.0]])
    assert observables(z, mu, T=1e-3)["H"].item() < 1e-6


def test_identite_thermodynamique():
    """Lemme 1 : F = <E> - T·H, à la précision machine."""
    torch.manual_seed(0)
    z = torch.nn.functional.normalize(torch.randn(64, 16), dim=-1)
    mu = torch.nn.functional.normalize(torch.randn(3, 16), dim=-1)
    for T in (0.05, 0.2, 1.0, 5.0):
        o = observables(z, mu, T)
        assert torch.allclose(o["F"], o["E"] - T * o["H"], atol=1e-5)


def test_invariance_de_H_covariance_de_F():
    """Proposition 2 : translater toutes les énergies laisse H inchangée
    et décale F d'exactement c. C'est le fondement du découplage."""
    torch.manual_seed(0)
    d2 = torch.rand(32, 5) * 4
    T, c = 0.3, 1.7
    H1 = entropy(torch.log_softmax(-d2 / T, -1))
    H2 = entropy(torch.log_softmax(-(d2 + c) / T, -1))
    assert torch.allclose(H1, H2, atol=1e-5)
    assert torch.allclose(free_energy(d2 + c, T), free_energy(d2, T) + c, atol=1e-4)

S4

Backbone instrumenté

3 h
Piège n°1 — le plus coûteux

Les forward hooks observent le calcul mais ne l'interrompent pas. Une sortie anticipée implémentée par hooks exécute quand même les douze couches et n'économise strictement rien — tout en produisant des courbes parfaitement plausibles. La boucle explicite sur backbone.blocks est obligatoire.

Les documents initiaux du projet prescrivaient les hooks. C'est corrigé ici.

tlsc/models/backbone.py
from __future__ import annotations

import timm
import torch
import torch.nn.functional as F
from torch import Tensor, nn


class ProjectionHead(nn.Module):
    """g_n : R^D -> S^{d-1}."""

    def __init__(self, width: int, d: int) -> None:
        super().__init__()
        self.norm = nn.LayerNorm(width)
        self.proj = nn.Linear(width, d)

    def forward(self, x: Tensor) -> Tensor:
        return F.normalize(self.proj(self.norm(x)), dim=-1)


class CrystallizationViT(nn.Module):
    """ViT instrumenté : lecture par couche, prompts visuels, centroïdes ancrés."""

    def __init__(self, backbone: str = "vit_small_patch16_224",
                 d: int = 256, n_classes: int = 2,
                 n_prompts: int = 10, prompt_layer: int = 3,
                 pretrained: bool = True) -> None:
        super().__init__()
        self.backbone = timm.create_model(backbone, pretrained=pretrained, num_classes=0)
        width = self.backbone.embed_dim
        self.n_layers = len(self.backbone.blocks)
        self.heads = nn.ModuleList(
            [ProjectionHead(width, d) for _ in range(self.n_layers)]
        )
        self.prompt_layer = prompt_layer
        self.prompts = (
            nn.Parameter(torch.zeros(n_prompts, width)) if n_prompts > 0 else None
        )
        if self.prompts is not None:
            nn.init.trunc_normal_(self.prompts, std=0.02)
        self.register_buffer("centroids", torch.zeros(self.n_layers, n_classes, d))

    def _embed(self, x: Tensor) -> Tensor:
        b = self.backbone
        h = b.patch_embed(x)
        h = b._pos_embed(h)
        return b.norm_pre(h)

    def forward_layers(self, x: Tensor, max_layer: int | None = None) -> list[Tensor]:
        """Embeddings z^(n) pour n = 1..max_layer.

        Le calcul s'arrête RÉELLEMENT à max_layer : c'est ce qui rend
        l'économie de FLOPs mesurable plutôt que fictive.
        """
        h = self._embed(x)
        out: list[Tensor] = []
        for n, blk in enumerate(self.backbone.blocks, start=1):
            if self.prompts is not None and n == self.prompt_layer:
                p = self.prompts.unsqueeze(0).expand(h.size(0), -1, -1)
                h = torch.cat([h, p], dim=1)
            h = blk(h)
            out.append(self.heads[n - 1](h[:, 0]))
            if max_layer is not None and n >= max_layer:
                break
        return out

S5

Gel et restauration

1 h
Piège n°2 — silencieux et dévastateur

ProjectionHead contient un nn.LayerNorm. Un parcours naïf de model.modules() l'inclurait dans θadapt, ce qui adapterait les têtes au moment du test et invaliderait tout l'ancrage des centroïdes. Les résultats seraient meilleurs, et faux. Ne parcourir que model.backbone.modules().

tlsc/adapt/state.py
from __future__ import annotations

import torch
from torch import Tensor, nn


def collect_adapt_params(model: nn.Module, use_ln: bool = True,
                         use_prompts: bool = True) -> list[nn.Parameter]:
    """Gèle tout, puis ré-active exclusivement theta_adapt."""
    for p in model.parameters():
        p.requires_grad_(False)

    params: list[nn.Parameter] = []
    if use_ln:
        # ATTENTION : model.backbone, surtout pas model — les têtes de
        # projection contiennent des LayerNorm qui doivent rester gelées.
        for m in model.backbone.modules():
            if isinstance(m, nn.LayerNorm):
                for p in (m.weight, m.bias):
                    if p is not None:
                        p.requires_grad_(True)
                        params.append(p)
    if use_prompts and getattr(model, "prompts", None) is not None:
        model.prompts.requires_grad_(True)
        params.append(model.prompts)
    return params


def snapshot(params: list[nn.Parameter]) -> list[Tensor]:
    return [p.detach().clone() for p in params]


@torch.no_grad()
def restore(params: list[nn.Parameter], snap: list[Tensor]) -> None:
    for p, s in zip(params, snap, strict=True):
        p.copy_(s)
tests/test_freeze.py — les deux tests non négociables
import torch
from tlsc.adapt.state import collect_adapt_params, restore, snapshot
from tlsc.models.backbone import CrystallizationViT


def _model():
    return CrystallizationViT(pretrained=False, n_prompts=4)


def test_backbone_intouche_apres_tta():
    """Après une étape d'adaptation, seul theta_adapt a bougé.
    C'est la vérification de la revendication centrale du papier."""
    m = _model()
    params = collect_adapt_params(m)
    frozen = {n: p.detach().clone() for n, p in m.named_parameters()
              if not p.requires_grad}

    opt = torch.optim.SGD(params, lr=1e-2)
    z = m.forward_layers(torch.randn(2, 3, 224, 224), max_layer=4)[-1]
    z.pow(2).sum().backward()
    opt.step()

    for n, p in m.named_parameters():
        if n in frozen:
            assert torch.equal(p, frozen[n]), f"paramètre gelé modifié : {n}"
            assert p.grad is None or torch.count_nonzero(p.grad) == 0


def test_pas_de_derive_entre_echantillons():
    """Deux inférences sur la même image donnent le même résultat après restore.
    C'est l'argument technique de la section conformité RGPD / HIPAA."""
    m = _model().eval()
    params = collect_adapt_params(m)
    snap = snapshot(params)
    x = torch.randn(1, 3, 224, 224)

    with torch.no_grad():
        z1 = m.forward_layers(x)[-1].clone()
    with torch.enable_grad():
        m.forward_layers(x)[-1].pow(2).sum().backward()
        torch.optim.SGD(params, lr=1e-1).step()
    restore(params, snap)
    with torch.no_grad():
        z2 = m.forward_layers(x)[-1]

    assert torch.allclose(z1, z2, atol=1e-6), "dérive de theta_adapt"

S8

Énergie en ligne et méthode proposée

2 jours

Le terme répulsif, rendu opérant par les prototypes souples, et le diagnostic d'effondrement qui l'accompagne obligatoirement.

tlsc/core/energy.py
from __future__ import annotations

import torch
from torch import Tensor

from tlsc.core.gibbs import observables


def soft_prototypes(z: Tensor, p: Tensor, eps: float = 1e-6) -> Tensor:
    """Prototypes souples différentiables. z (B,d), p (B,K) -> (K,d).

    C'est cette différentiabilité qui donne au terme répulsif un gradient
    non nul — la formulation à centroïdes figés le rendait inerte.
    """
    w = p.t()                              # (K, B)
    num = w @ z                            # (K, d)
    den = w.sum(-1, keepdim=True).clamp_min(eps)
    return num / den


def online_energy(z: Tensor, mu_anchor: Tensor, T: float, lam: float,
                  beta: float) -> tuple[Tensor, dict[str, Tensor]]:
    """Énergie en ligne : condensation - répulsion + ancrage (Définition 4)."""
    obs = observables(z, mu_anchor, T)
    mu_hat = soft_prototypes(z, obs["p"])

    condensation = obs["H"].mean()
    repulsion = torch.cdist(mu_hat, mu_hat).pow(2).max()
    anchoring = (mu_hat - mu_anchor).pow(2).sum(-1).mean()

    loss = condensation - lam * repulsion + beta * anchoring

    p_bar = obs["p"].mean(0)
    logs = {
        "condensation": condensation.detach(),
        "repulsion": repulsion.detach(),
        "anchoring": anchoring.detach(),
        # DIAGNOSTIC D'EFFONDREMENT — une chute invalide le run
        "marginal_entropy": -(p_bar * p_bar.clamp_min(1e-12).log()).sum().detach(),
    }
    return loss, logs

from __future__ import annotations

import math
import numpy as np


def hoeffding_ucb(risk_emp: float, m: int, delta: float) -> float:
    """Borne supérieure de confiance de Hoeffding sur le risque."""
    return risk_emp + math.sqrt(math.log(1.0 / delta) / (2.0 * m))


def learn_then_test(scores: np.ndarray, correct: np.ndarray,
                    offsets: np.ndarray, grid: np.ndarray,
                    alpha: float, delta: float) -> float | None:
    """Sélectionne le seuil le plus agressif dont le risque reste contrôlé.

    Parameters
    ----------
    scores : (m, L)   critère de sortie Phi_n, par échantillon et par couche
    correct : (m, L)  la prédiction de la couche n est-elle correcte
    offsets : (L,)    normalisation par couche (médiane de Phi_n en domaine source)
    grid : (G,)       candidats eps0, du plus conservateur au plus agressif
    alpha, delta : niveau de risque et confiance

    Returns
    -------
    Le eps0 retenu, ou None si aucun candidat ne contrôle le risque.
    """
    m = scores.shape[0]
    retained: float | None = None
    for eps0 in grid:                        # test par séquence fixe
        thr = offsets + eps0                   # (L,)
        exits = scores < thr[None, :]
        first = np.where(exits.any(1), exits.argmax(1), scores.shape[1] - 1)
        risk_emp = 1.0 - correct[np.arange(m), first].mean()
        if hoeffding_ucb(risk_emp, m, delta) <= alpha:
            retained = float(eps0)             # valide, on tente plus agressif
        else:
            break                              # premier échec : on s'arrête
    return retained

def total_flops(fwd_probe: float, fwd_exit: float, n_steps: int,
                rho: float, kappa: float = 2.0) -> float:
    """FLOPs par image, passes ARRIÈRE incluses (§7 du cadre théorique).

    kappa : coût de la passe arrière relativement à la passe avant.
        La valeur 2.0 est une convention. Elle DOIT être validée
        empiriquement pour ce modèle et ce matériel, puis rapportée.
    """
    return rho * n_steps * (1.0 + kappa) * fwd_probe + fwd_exit

Mesure de κ : chronométrez une passe avant seule, puis avant + arrière, sur le même lot ; le rapport moins un donne κ. Rapportez la valeur mesurée plutôt que la convention.

def measure_latency(fn, warmup: int = 20, iters: int = 100) -> tuple[float, float]:
    """Latence p50 / p95 en millisecondes.

    L'échauffement et la synchronisation sont indispensables : sans eux,
    on mesure la vitesse d'enfilement des kernels, pas leur exécution.
    """
    import numpy as np
    import torch

    for _ in range(warmup):
        fn()
    torch.cuda.synchronize()

    ts = []
    for _ in range(iters):
        s, e = torch.cuda.Event(True), torch.cuda.Event(True)
        s.record(); fn(); e.record()
        torch.cuda.synchronize()
        ts.append(s.elapsed_time(e))
    return float(np.percentile(ts, 50)), float(np.percentile(ts, 95))
